How to Get a Facebook Access Token

  1. Go to the Facebook Graph API Explorer
  2. Select your app or create a new one
  3. Add these permissions:
    • pages_read_engagement (for page posts)
    • public_profile
  4. Click "Generate Access Token"
  5. Copy the token and paste it below

API Configuration

The access token enables API-based comment fetching for more reliable results. If not provided, the extension will try to scrape comments from the page.
Note: User access tokens expire quickly (usually within 1-2 hours). For extended use, consider getting a Page Access Token or App Token from the Facebook Developer Console.
